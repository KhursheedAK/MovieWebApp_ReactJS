## About
Migrated a vanilla JavaScript movie application to React to practice modern state management and component-based architecture. Key implementations include lifting state up for cross-component data sharing, handling dynamic props, and integrating the OMDB API to deliver real-time search results. Focused on creating modular, reusable components to improve code maintainability and scalability.

## Features
- Search movies by title using the OMDB API
- Paginated results (3 movies per page)
- Displays movie poster, title, year, and type
- Fallback placeholder image for movies with no poster

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- OMDB API
- GitHub Pages

## Running Locally

```bash
npm run dev
```
